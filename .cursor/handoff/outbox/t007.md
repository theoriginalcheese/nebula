## Changed

- `spike/windows.py`
  - **`atexit.register`** on `NebulaWindows` — calls `destroy()` on normal/exception process exit
  - **`_LivenessWatch`** daemon thread (3s) — closes toast/overlay when host PID, main HWND, or `_quitting` is gone
  - **`reclaim_orphan_windows()`** — called at `NebulaWindows` init; `EnumWindows` + exact title match (`Nebula Toast` / `Nebula Overlay`); closes foreign PIDs via `PostMessage(WM_CLOSE)`, `EndTask` fallback, or `DestroyWindow` when owner PID is dead
  - **`_teardown_without_host()`** — force-destroys controllers off the GUI thread when liveness detects a dead host
  - Idempotent teardown lock so `destroy()`, liveness, and atexit cannot double-close

- `tests/test_v4_windows.py`
  - **`test_reclaim_orphans`** — foreign PIDs get WM_CLOSE; same-PID kept
  - **`test_reclaim_dead_pid`** — dead-owner path uses DestroyWindow
  - **`test_liveness_teardown`** — host `_quitting` triggers force destroy
