## Host wiring needed (cannot edit `host.py` / `app.py` here)

Create and own a `NebulaWindows` instance on the host:

```python
from spike.windows import NebulaWindows
# in NebulaHost.__init__ or attach_backend:
self._windows = NebulaWindows(self, self.config)
```

| Call site | Method |
|-----------|--------|
| `_on_notify(event, display_name, details)` | `self._windows.toast_replace(event, display_name, details)` — replace the log-only stub |
| `_poll_obs_status()` after state/readout change | `self._windows.overlay_sync()` — closes overlay when recording ends; pushes elapsed/game |
| New `show_mini()` (tray / palette) | `self._windows.overlay_show()` |
| New `hide_mini(restore=False)` | `self._windows.overlay_hide(restore=restore)` |
| `quit()` | `self._windows.destroy()` before main window teardown |

Mark clip is handled inside `OverlayController._mark_clip()` via `session_log.append` when `host._is_recording` is true — no `Api` change required unless you prefer routing through `spike/app.py`.
