## Api blocker found (not fixed — out of file ownership)

`palette_search()` throws once the host is attached:

```
TypeError: 'bool' object is not callable
  app.py:523  host.replay.enabled()
  host.py:811  self.replay.enabled()
```

`ReplayBuffer.enabled` and `.seconds` are **properties** in `obsauto/replay.py`, not methods. UI is complete; rows cannot populate until `app.py` / `host.py` drop the `()`.

Suggested fix (for whoever owns those files):

```python
# app.py _palette_rows
if host and host.replay and host.replay.enabled:
    add(..., "Save the last %ds" % host.replay.seconds, ...)
# host.py start_replay
if not self.replay.enabled:
```
