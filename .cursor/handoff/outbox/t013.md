## Placement choice

**Pane header, next to Done** — not pinned under the grid.

The old `#dash-add-row` sat after `#dash-grid` inside `#pane-dashboard`. The grid is `flex: 1` and the activity block grows to fill the pane, so the add row was pushed below the fold and visually collided with the activity list / rail storage block. Moving it into `.pane-header-tools` (alongside `#pane-actions`) keeps it fixed, always visible without scrolling, clearly part of edit mode, and clear of the grid and rail.

## Root cause (add-back felt broken even after header move)

`applyDashLayout()` updated the layout array and reordered DOM nodes but **never hid blocks removed from the layout**. A removed module stayed in the CSS grid, so the add chip looked redundant and clicking × appeared to do nothing. Fixed with `syncDashBlockVisibility()` — sets `hidden` on any `.dash-block` whose id is not in `dashLayout`.

## Changed

- `spike/web/index.html` — `#dash-add-row` moved from bottom of `#pane-dashboard` into `.pane-header-tools` beside `#pane-actions`.
- `spike/web/app.css` — header tools flex row; add-row/chip styling for header context; span/close hit targets raised to 30px without changing `--handle-strip-h`; active span matches `.rail-item.is-active` / `.palette-row.is-active` (`.14` fill + accent border); drop marker gets fill + opacity transition; grid overlay brightens while dragging; restore chip pulse (`dash-restore-pulse`) with reduced-motion pause; `.dash-block[hidden]` excluded from grid.
- `spike/web/app.js` — `syncDashBlockVisibility()`; `dashRecentlyRemoved` tracks last × removal → chip label becomes **Restore …** with `is-recent` class; `setDashDragging()` for pointer + keyboard drag; dev boot hook `dashomit=` for screenshot (`?customise=1&dashomit=activity`).

## Controls polish

| Issue | Fix |
|---|---|
| Add row unreachable | Header placement (above) |
| × appears to do nothing | Hide removed blocks from grid (`syncDashBlockVisibility`) |
| Strip controls < 30px | `min-width/min-height: 30px` on span + close buttons |
| × is a cliff | Recently removed module → **Restore {name}** chip, accent border, gentle pulse |
| Drag landing unclear | Drop marker filled + fades in; grid overlay columns brighten while `.is-dragging` |
| Active span idiom | Matches rail/palette `.14` + border, not the old `.28` fill |
